# MathRaids

MathRaids is a cooperative classroom maths game where students join a live raid, answer maths questions, and work together to defeat a shared boss.

## Product principles

- Shared raid progress, private individual performance.
- No public student leaderboards.
- Teacher-only learning reports.
- Guest-first classroom join flow for the MVP.
- Monetisation should focus on teacher and school tools, not pay-to-win student mechanics.

## MVP

The first vertical slice targets a teacher-created raid room, six-character join codes, up to 60 students, DPS and Healer roles, multiple-choice maths questions, simple left/right/jump raid mechanics, one city boss encounter, and a private teacher report.
